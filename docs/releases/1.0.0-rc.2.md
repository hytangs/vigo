# VIGO 1.0.0-rc.2

This is the second VIGO 1.0 release candidate. It integrates GTFS Flex with fixed service in one timetable search and makes wheelchair routing usable where OpenStreetMap does not tag every sidewalk.

## GTFS Flex and fixed service in one search

A conditional ride that ends at a transit stop is now time-dependent access to the timetable scan, and one that starts at a transit stop is time-dependent egress. A journey can use Flex to reach fixed service, Flex to leave it, or both, departing or arriving by. Zones, location groups, published booking stops and continuous stopping share one ride model, so each request enumerates only the Flex trips its endpoints can reach.

The scheduled search itself scans Flex access and egress with optimistic values, so a request where Flex cannot win costs one search, as without Flex. A winning Flex journey is confirmed with street walks and exact clocks; it may be up to 60 seconds later than the best conditional journey, and larger differences are searched again exactly. A broken transfer rule at a Flex interchange falls back to composing the two halves separately.

Deviated routes keep their fixed calls: a rider carried past a fixed stop is picked up in time for the vehicle to reach it on schedule, with assumption `deviated_route`. Each Flex ride counts as a boarding.

## Wheelchair routing with inferred street evidence

The `wheelchair-strict-v1` profile still excludes unknown vehicle and boarding accessibility. Its street evidence is now chosen at preparation. By default, `--wheelchair` uses ordinary paved pedestrian ways unless OpenStreetMap records steps, a rough surface, bad smoothness, a mountain trail grade, an incline above 8.3%, a width below 0.9 m, a raised or unrecorded kerb, or a barrier other than an unlocked gate or bollard. `--wheelchair-streets verified` keeps the previous rule, which uses only ways tagged `wheelchair=yes`. Every result's `accessibility.streetEvidence` names the rule its City was prepared with.

Inferred streets are not surveyed: a result is a route the published data does not rule out, not a guarantee. Rebuild a wheelchair City to use inferred streets; existing wheelchair Cities keep their verified-only street graph.

## Compatibility and packages

API 1.0, City format 1 and Result schema 1 remain unchanged. Compatible prepared Cities remain readable without rebuilding, and new wheelchair Cities keep the profile identifier the reference runtime reads. The frozen reference compatibility fixture remains part of release validation.

The corresponding Python version is `1.0.0rc2`. Engine tags use `v1.0.0-rc.2`; Python tags use `python-v1.0.0rc2`. Bundled Python runtimes come from the same repository commit.
