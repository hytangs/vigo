# VIGO 0.5.2

VIGO 0.5.2 focuses Studio on network inspection, routing, and analysis, with
embedded documentation, better result saving, and less redundant backend work.

## Studio

Open **Settings → Documentation** to read the searchable Studio/engine guide
and CLI/HTTP reference offline, in the current light or dark appearance. The
same Markdown sources generate the standalone readers and bundled pages.

The former Ask interface, City agency skills, and their unused tests and
evaluation fixtures are removed. Network, Routes, Route, Analyze, model-backed
service briefings, and saved City evidence remain available. Saved Ask tabs
reopen Network; retained notebook records require no migration.

## Save and compare results

Journey details export JSON, GeoJSON, CSV, and readable Markdown. Downloads
retain selected alternatives, source geometry, service clocks, and initial
waiting separately from journey duration. Reach and City/scenario comparisons
retain query settings and reference results. Comparison summaries distinguish
faster/newly reached cells from slower/lost cells and keep missing evidence
unavailable. Preliminary computations cannot be exported as complete results.

## Routing and Reach

Point queries reject provably later candidates earlier and avoid constructing
an intermediate journey that exact capped certification would discard. The
earliest-arrival/latest-departure, boarding, and walking objectives remain
unchanged. Ordinary Node Route replies avoid passing unused search diagnostics
through the public formatter; requested diagnostics remain available.

Reached-street propagation uses an exact monotone queue with a fallback for
nonmonotone inputs. Small and fractional walking budgets remain exact, and
contours preserve geographic bends and exact-cutoff samples. Repeated schedule
diagnostic lookups use a bounded service-specific cache. City activation and
preparation timings distinguish setup from query work.

Street import exposes **Public** and **Authorized endpoints** pedestrian access.
Public remains the default. Authorized endpoints can connect a permitted origin
or destination through restricted paths; they do not enable private through
shortcuts. Replacing streets clears obsolete endpoint overlays.

## Compatibility and measurement

Published 0.5 Cities remain readable without rebuilding. API 1.0, City format 1,
and Result schema 1 are unchanged. The [permanent 0.5 data contract](../reference/format-0.5.0.md)
remains authoritative. Existing sources, routing policies, and scenario semantics
are preserved.

Performance depends on the City, endpoints, query, output, and runtime. Measure
City opening, native search, result construction, and transport separately;
see [measurement guidance](../developer.md#measuring-performance). This release
does not make a universal sub-millisecond latency claim.
