# VIGO 1.0.0

VIGO 1.0.0 builds reusable transport Cities from GTFS and OpenStreetMap and
answers Route, Matrix and Reach queries through the native engine, command
line, Studio and Python. API 1.0, City format 1 and Result schema 1 retain
their existing meanings. Published Cities remain readable without rebuilding.

## Routing and preparation

Studio groups services with the same ordered platforms and access paths even
when their GTFS shapes differ by small coordinate rounding. Each departure
retains its own line, times and geometry. Express-to-local journeys can keep
the express to a later shared platform when the same onward train remains
catchable, with unchanged endpoint times, boardings and walking. Pickup,
drop-off, transfer restrictions and the requested buffer remain enforced.

Bicycle Route, Matrix and Reach use a turn-aware customizable contraction
hierarchy. Shared rank sweeps evaluate departure and arrival grids, retaining
each endpoint's private-road permissions. One relaxed sweep from the fixed
endpoint bounds how far each grid cell searches for walking access; cells the
path certificate cannot settle repeat with every walking candidate. Supported timed roads and turns
are checked at entry. The selected preference profile ranks paths while the
result reports actual cycling, walking and waiting time.

Existing Cities remain readable. Local source-checked graph indexes can reuse
the hierarchy when a worker opens a City. They keep the upward hierarchy and
shortcut witnesses; opening rebuilds the remaining columns and weights
exactly. The indexes are derived from the original City and store no route
or surface answers.
Studio includes Bike in Reach for both departure and arrival isochrones.

Scheduled and realtime journeys, bicycle preferences, driving traffic,
wheelchair profiles, planned services and Monte Carlo analyses use the shared
native computation layer. Planned services preserve arrival, dwell and
departure times across adjacent service days. Wheelchair preparation connects
accessible platforms without declared entrances and retains explicitly
accessible ramps whose incline gives a direction without a numeric grade.
Rebuild a City to apply these preparation corrections to existing inputs.

The bicycle hierarchy enforces the distance limit together with timing and
access rules. Transit Matrix scans index endpoints by stop, scenario exclusions
use one timetable pass, and Reach drops walking labels whose continuations
cannot improve the surface.

Studio address search filters suggestions to the selected City’s prepared street extent, with timetable coverage as a fallback. Switching Cities or replacing their data invalidates the regional lookup. Missing coverage never triggers a global search.

## Runtime and reproducibility

The engine supplies Studio's complete query fingerprint, including the City,
scenario, waypoints, alternative selectors and applicable realtime snapshot.
Street publication refreshes Studio's provenance independently of the timetable.
Native responses enforce their byte limit for complete and fragmented lines,
and busy City slots return a capacity error when the resident limit is reached.

Replacement processes prepare walking, bicycle, driving or timetable state
directly. Studio prepares the mode selected in Route or Reach while the City
opens, including the result-rendering binding. Reach and Matrix requests stay
on a worker whose corresponding network is loaded. Replacement workers retain
only mode and timetable selectors, never a user journey or surface. The public gateway rotates
rate-limit buckets once per minute. Interrupted City builds wait for compilers
to close before removing unpublished output.

## Dependencies

The release updates the npm and Rust dependency sets together. The maintained
GroveDB bincode codec replaces the unmaintained upstream crate, using the
existing fixed-width encoding for prepared access profiles.

## Distribution

Engine, CLI, Studio and Python bundles are built from the same source commit
for Linux x64/arm64, macOS arm64 and Windows x64. Release publication requires
the platform checks, isolated Python wheel integration, City portability,
container checks and artifact checksums. The Python package is version 1.0.0.
