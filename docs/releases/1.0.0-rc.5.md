# VIGO 1.0.0-rc.5

RC.5 makes bounded street routing answer quickly, keeps Cities safe through
interrupted builds, and hardens the public route planner. API 1.0, City format 1
and Result schema 1 retain their field meanings, and published Cities open
without rebuilding.

## Distance limits

Bicycle Route and Matrix requests with a street distance limit bound their
search by exact remaining distance and preference cost. A request whose
endpoints cannot be joined within the limit reports no route at once, and a
straight line longer than the limit skips the unconstrained search. When a
tight limit leaves too many trade-offs to prove the preferred route, VIGO
returns the shortest route within the limit and adds the warning
`distance_limit_shortest_route`; such a route may not be the best for the
chosen preference. Requests cannot select that internal shortest profile.

Driving requests over a street distance limit start from the feasible shortest
path and use exact remaining bounds. Long limits no longer search for seconds
and then report a false `not_found`, and short limits keep their earlier speed.

The bicycle graph loads without an on-disk sort, about halving its cold load
time. Answers are unchanged.

## Journeys and Cities

Adding a stop to a journey from A to B now gives A, B, then C. The earlier
destination becomes the stop before the new one; reordering is unchanged.

`vigo build` flushes a finished City to disk before publishing it and keeps the
old City until the new one is on disk. If a crash interrupts a replacement, the
next `vigo build` or Node CLI query of that path restores the old City or
finishes the swap, and removes abandoned build directories. Directories owned
by a live process or another host are left alone. The Rust executable only
reads, so it reports such a City as missing until then. Interrupt signals stop
the compilers and remove the unfinished build.

A City's process receives only the running query, so a cancelled query that is
still waiting never runs.

## Public route planner and Studio

The public gateway can answer address searches from a local SQLite index on a
worker thread with a two-second limit, keeping typed text on the host. Hashed
assets are cached as immutable, the document revalidates by `ETag` and carries
its security policy as a header, and reads are metered per IP. The edge serves
a temporary offline page when the routing host is unreachable. See the
[public route planner guide](../guides/public-routing.md).

Studio restores its offline default basemap, contacts a geocoder only after
online maps are chosen, and loads its library, network, analysis and scenario
views on first use.

Python `1.0.0rc5` accompanies this release and bundles the same engine.
