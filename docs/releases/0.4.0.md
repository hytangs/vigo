# VIGO 0.4.0

VIGO 0.4.0 integrates the network inspection work developed in the VIGO Agency fork into VIGO Studio. The Engine, Studio, and separate Python interface retain the City → Scenario → Query → Result model. API 1.0, City format 1, and Result schema 1 remain unchanged.

- Network reporting, route inspection, station boards, schematic line views, and scheduled/predicted trip times are available in Studio.
- Ask provides an experimental model interface to deterministic transit tools, with sources and an inspectable activity trail.
- Transit Route distinguishes scheduled queries from immutable supplied realtime snapshots. Matrix and Reach remain scheduled.
- Added realtime service appears in line views and the trip selector even without a static trip. Only reported stops and absolute predictions are shown; no scheduled times or delays are invented.
- Via-point routes disable unsupported transfer caps. Routing failures stay with the route state and clear when the request recovers.

The former product README and release history are retained and updated. The fork's AI-use and assumptions documents are removed. The source and desktop use the VIGO identity and existing VIGO storage defaults.
