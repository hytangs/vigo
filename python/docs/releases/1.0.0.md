# VIGO Python 1.0.0

VIGO Python 1.0.0 provides City, Scenario, Route, Matrix, Reach and Result
objects for scripts and notebooks. Platform wheels bundle Engine 1.0.0 from
the same source commit and run without a host Node or Rust installation.

The package has no mandatory Python dependencies. Install the `speed` extra
for accelerated JSON decoding and `progress` for build progress displays.
Reuse an open City for repeated queries; `iter_run()` bounds concurrent work,
and `Result.iter_rows()` iterates a retained result without constructing a
second row list.

The bundled engine includes bounded bicycle and driving searches, adjacent-day
planned service, corrected wheelchair preparation, and crash-safe City
replacement. Existing API defaults and prepared City compatibility remain.

Download the platform wheel from the GitHub release and follow the
[guide](../guide.md). Source distributions remain available for use with an
external Engine. These releases are distributed on GitHub.
