# VIGO Python 0.5.0

Use Engine 0.5 and rebuild prepared Cities with that engine. Earlier runtimes are rejected during runtime selection.

Route, Matrix, and Reach share the documented `stream` command with an explicit query kind. The private `_route-stream` protocol, one-shot fallback for older runtimes, and order-dependent JSON decoder are removed. Detailed Python Results use explicit trace output; ordinary Engine CLI and Studio responses remain compact.

Walking Reach, street or cell-center sampling, optional reached street edges, and structured stop references are available from Python.

Result access uses faster JSON-tree copies; `iter_rows()` copies only consumed rows, and CSV export avoids copying the matrix. Install the optional `speed` extra for accelerated resident-response decoding. Run `scripts/benchmark-wrapper.py` to measure these Python costs separately from routing.

Production queries use only the shared resident query stream. The test suite runs independent one-shot CLI calls for parity checks. Runtime selection requires API 1.0, capability schema v3, and trace output. Obsolete point aliases, index-only Matrix comparison, and generic non-JSON Result copying are removed.

Stored Results keep their original evidence. Route exports use one serialization path for all journeys, including Unicode names and full geometry precision.
