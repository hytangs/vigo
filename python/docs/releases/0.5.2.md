# VIGO Python 0.5.2

The Python package now lives in `python/` in the VIGO repository. Its distribution and import name remain `vigo`; source installations still need no frontend toolchain. Wheels are built and tested against the engine in the same commit, including Engine 0.5.2. Existing compatible Engine 0.5 installations remain usable.

Route accepts `alternatives=3` (0–9), `alternative_ranking="pareto"` or `"ranked"`, and `alternative_slack_minutes=15` (0–120). These options require an engine advertising canonical detailed alternatives and depart-at transit without waypoints or a departure window. Alternatives remain off by default. `result.choices` preserves the engine's selected journeys and `result.alternative_search` reports coverage and completion; `result.value` remains the primary journey.

Installing the `speed` extra enables direct decoding of UTF-8 response bytes without first allocating a Python string. Standard-library decoding remains available. Resident process reuse, full itinerary fields, geometry, strict request encoding and independent result copies are retained. Engine routing improvements and Python serialization overhead are distinct; measure complete workloads with identical query and output settings before claiming a speedup.

Python release tags use `python-v0.5.2`; engine releases use their own tags. Platform support is established by the corresponding CI lane, not by a local wheel build alone.
