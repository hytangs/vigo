# VIGO Python 1.0.0rc3

This is the third Python release candidate corresponding to Engine `1.0.0-rc.3`. Python uses PEP 440 version spelling; engine and Python tags remain separate.

The wrapper validates API 1.0, City format 1, Result schema 1 and required runtime capabilities. Bundled wheels require a VIGO V1 runtime from the same repository commit.

Route, Matrix and Reach computation stays in Rust. Python retains input validation, bounded resident-process batches and Result decoding and presentation. Source wheels install without Node or Rust; bundled wheel checks exercise the shipped runtime independently of host tools.

The bundled runtime answers exactly as Engine `1.0.0-rc.2` did, with less repeated work in journey windows and Reach. A resident `City` process frees its street search scratch after 30 seconds without a query, returning the pages on Linux with glibc; set `VIGO_IDLE_RELEASE_MS` to change that.

See the [guide](../guide.md) and [changelog](../../CHANGELOG.md).
