# VIGO Python 1.0.0rc5

This Python release candidate accompanies Engine `1.0.0-rc.5`. The Python API,
query defaults and dependencies are unchanged; bundled wheels carry the new
engine.

Bike queries with a street distance limit now return quickly. When a tight
limit leaves too many trade-offs to prove the preferred route, the result is
the shortest route within the limit, with the warning
`distance_limit_shortest_route`. Driving queries over a distance limit no longer
report a false blocked outcome after a long search.

`build(..., replace=True)` flushes the new City before replacing the old one.
If a crash interrupts the replacement, the next build of that path restores
or finishes it.

See the [engine release notes](https://github.com/hytangs/vigo/blob/v1.0.0-rc.5/docs/releases/1.0.0-rc.5.md) and the
[changelog](../../CHANGELOG.md).
