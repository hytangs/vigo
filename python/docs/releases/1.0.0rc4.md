# VIGO Python 1.0.0rc4

This Python release candidate accompanies Engine `1.0.0-rc.4`. Computation stays
in the shared Rust engine; the package adds no mandatory dependencies.

Route, Matrix and Reach accept `mode="bike"` and an optional `bike` mapping with
`profile`, `speedKph` and `maxLts`. Build bicycle streets explicitly with
`street_modes="walk,bike"` or `"walk,drive,bike"`. Existing build and query
defaults remain unchanged. Reach also exposes the engine's driving mode.

The three query families accept `monte_carlo` for scheduled transit departure
windows. Results retain the native distribution, seed, sample count, percentiles,
unreachable counts, assumptions and provenance. Planned service scenarios and
optional accessibility indicators use the same sampler. This models variation
in departure times and unknown frequency schedules, not observed delays.

Use `iter_rows()` or CSV export to read distributions one row at a time without
copying the complete table. JSON retains the full native contract. Comparisons
report differences of matching marginal percentiles; they do not claim a
distribution of paired changes. A distribution supplies no representative
journey or contour geometry.

Older runtimes remain usable for existing queries. New features require explicit
capabilities and fail before opening a query stream when support is missing.
See the [reference](../reference.md#bike-and-monte-carlo-options) for accepted
options, limits and result units.
