# Network briefing

## Question
What can the current feed observation establish about service, and what remains unknown?

## Method
Use the shared computed network diagnosis: all indexed routes, schedule-window coverage, distinct reporting trips and exact shared stop connections. Check each feed timestamp separately. Compare adjacent scheduled departures only where both trips report a departure prediction at the same stop. Read agency alerts as published statements. Keep predicted intervals separate from actual vehicle movements.

## Interpretation
Lead with the spread of late predictions, then distinguish shared-area delays from longer rider waits. Keep precise counts and timing comparisons as supporting evidence. Describe missing or unresolved observations. Do not equate missing events with regular service, assign an arbitrary health score, infer causes, or invent a recovery time.

The Overview briefing can additionally investigate candidate explanations through bounded AI evidence checks. This research skill retains the computed assessment and supporting tables without another model call.

## Reuse
The saved note includes its exact observation time and tool responses. A later refresh creates a new note rather than rewriting this evidence.
