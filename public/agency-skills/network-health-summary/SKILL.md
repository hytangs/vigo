# Network briefing

## Question
What can the current feed observation establish about service, and what remains unknown?

## Method
Check each feed timestamp separately. Compare adjacent scheduled departures only where both trips report a departure prediction at the same stop. Read agency alerts as published statements. Keep predicted intervals separate from actual vehicle movements.

## Interpretation
Name the route, reference stop, predicted interval, and scheduled interval. Describe missing or unresolved observations. Do not equate missing events with regular service, assign an arbitrary health score, infer causes, or invent a recovery time.

## Reuse
The saved note includes its exact observation time and tool responses. A later refresh creates a new note rather than rewriting this evidence.
