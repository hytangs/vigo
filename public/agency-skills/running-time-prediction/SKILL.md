# Running-time prediction review

Read the selected City's saved LAMP study. Compare the historical predictor with the applicable archived timetable on identical held-out segment observations. State training and evaluation dates, coverage, absolute errors and bias. Inspect route and segment differences instead of assuming the network average applies everywhere. Dates in the evaluation must never enter model fitting.

These are reconstructed stop-event running times. LAMP can use final arrival predictions where vehicle-position events are absent; do not label the target independent ground truth. Do not translate historical segment accuracy into a live delay cause, a recovery forecast or a passenger-impact estimate. Report missing coverage or a worse model honestly. A filtered route view retains an explicitly labeled study-wide comparison and separately filtered route results.
